# إدارة مرتبي - نسخة أولية

## الموجود في النسخة
- تسجيل الإيرادات والمصروفات والادخار.
- تصنيفات افتراضية قابلة للاستخدام.
- لوحة ملخص وسجل حركات.
- تصدير واستيراد نسخة احتياطية JSON.
- دعم PWA مبدئي للعمل كتطبيق عند استضافته عبر HTTPS.

## مهم جداً
هذه نسخة أولية تحفظ البيانات محلياً على الجهاز عبر LocalStorage. **لا توجد مزامنة تلقائية بين Honor 8X وSamsung A34 بعد**. نقل البيانات حالياً يتم يدوياً من تبويب النسخ الاحتياطي. لتفعيل المزامنة الحقيقية نحتاج ربط التطبيق بخدمة سحابية وقاعدة بيانات وتسجيل دخول، ثم نشره على رابط HTTPS.

## التشغيل التجريبي
افتح index.html في متصفح حديث. وللتثبيت كتطبيق PWA يلزم رفع الملفات إلى استضافة HTTPS ثم اختيار "إضافة إلى الشاشة الرئيسية" من Chrome.
